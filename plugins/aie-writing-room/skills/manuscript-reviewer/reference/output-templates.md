# Output Templates

The exact shape of each deliverable, so reviews stay consistent and comparable. Tables below show the default eight dimensions; if the book uses a custom rubric, list its dimensions instead.

---

## Per-chapter report (option 2)

```
# Chapter Review — [chapter title]
*[Book title] · manuscript-reviewer · [YYYY-MM-DD]*

## Scores
| Dimension                | Score | Weight | Weighted | Band |
|--------------------------|-------|--------|----------|------|
| Theme & Meaning          |  __   | 0.13   |   __     |  __  |
| Story Engine             |  __   | 0.14   |   __     |  __  |
| Character                |  __   | 0.14   |   __     |  __  |
| World & Authenticity     |  __   | 0.12   |   __     |  __  |
| Voice & Prose            |  __   | 0.12   |   __     |  __  |
| Dialogue                 |  __   | 0.11   |   __     |  __  |
| Pacing & Structure       |  __   | 0.14   |   __     |  __  |
| Hook & Reader Conversion |  __   | 0.10   |   __     |  __  |
| **FINAL**                |       |        | **__**   |      |

## What worked
[2–4 specific things, at most one short quote each]

## What didn't
[2–4 specific things, ordered by impact]

## Auto-flags fired
[List, or "None"]

## Fix queue (next pass)
1. [highest-impact change]
2.
3.
4. [optional]
5. [optional]
```

```
# [Book title] — Manuscript Review
*manuscript-reviewer · [YYYY-MM-DD] · Chapters: [N] · Words: [W]*

## Headline
[One sentence: the book's current state in plain English.]

## Manuscript scores
[Same table, computed as word-count-weighted averages]

## Decision threshold
[Submit / one more pass / major revision / back to outline]

## Top 5 chapters
| # | Chapter | Score | Why it works |

## Bottom 5 chapters
| # | Chapter | Score | Diagnosis |

## Auto-flags
1. Theme 85+ but Story Engine <60 → [pass / FIRED]
2. Voice 85+ but Character <60 → [pass / FIRED]
3. Any chapter Pacing <40 → [pass / FIRED — chapters]
4. Strong early character vanishing by midpoint → [pass / FIRED]
5. Manuscript Hook & Reader Conversion <70 → [pass / FIRED]
6. First-30-pages average (Story, Pacing, Hook) <75 → [pass / FIRED]

## Strengths
[3, with chapter examples]

## Weaknesses
[3, with chapter examples]

## Three highest-leverage revisions
1.
2.
3.
```

## Writer-panel debate (option 3)

```
# Writer Panel — Reviewers Debate
*Target: [chapter or "full manuscript"] · [YYYY-MM-DD]*
*Panel: [names; note any substitution]*

## Round 1 — Opening verdicts
**[Reviewer]:** [verdict in voice]   (× panel size)

## Round 2 — Cross-examination
[4–8 short exchanges, in voice]

## Round 3 — One concrete revision each
**[Reviewer]:** [specific change]   (× panel size)

## Synthesis
**Where the panel agrees:**
- 
**Where the panel disagrees (author decides):**
- [question]
**Highest-leverage revision:**
[one fix, named specifically]

## Rubric scores (computed before the panel spoke)
[table]
```

## Reader-panel debate (option 4)

```
# Reader Panel — Reviewers Debate
*Target: [chapter or "full manuscript"] · [YYYY-MM-DD]*

## Round 1 — "Did you finish it?"
**[Archetype]:** [answer in voice]   (× 5)

## Round 2 — "What stuck?"
[4–8 short exchanges]

## Round 3 — "Would you recommend it?"
**[Archetype]:** [yes / no / conditional, with reason]   (× 5)

## Synthesis
**Where readers agree:**
**Where readers disagree:**
**Conversion verdict:** [How many of five would finish / recommend / buy a copy for someone, and what that means]
```

---

## Both panels (option 5)

Writer-panel template, then reader-panel template, then:

```
## Writer-Reader Gap
**Writers see, readers don't:** [craft issues invisible to consumption]
**Readers see, writers don't:** [pacing or accessibility the writers tolerated]
**Top integrated revision:** [one fix that addresses both]
```

```
-
```

## Auto-flag scan (option 7)

```
# Auto-Flag Scan — [target] · [YYYY-MM-DD]

[For each flag that fired:]
**Flag [N]:** [name]
**Where:** [chapter / location]
**Diagnosis:** [one sentence]
**Fix:** [one sentence]

[If none:] No auto-flags fired. Clean scan.
```

## Revision priority list (option 8)

```
# Revision Priority List
*Source: [prior review or "this conversation"] · [YYYY-MM-DD]*

| # | Item | Chapter(s) | Effort | Impact | Why this rank |
|---|------|------------|--------|--------|---------------|
| 1 | | | S/M/L | High/Med/Low | |

## How to work this list
- Items 1–3 first; everything else depends on them
- Then in order, checking off as you go
- Re-score affected chapters after each item to confirm the lift
```
