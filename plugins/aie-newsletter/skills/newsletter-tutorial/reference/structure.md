# Tutorial — structure

`{K}` is `voice.kicker_prefix` (default `// `). `{Edition}` is
`editions.tutorial.name`.

## Skeleton

```markdown
**{K}{Edition}**

# How to [outcome] by [method]

[Featured image]

[First-person hook — 1–3 paragraphs. A real problem the author hit, told
plainly. This is what makes a how-to feel earned instead of generic.]

### [Action subhead, imperative — e.g., "Train the assistant before you blame the interface."]

**{K}The Takeaway:** [One bolded paragraph with the whole lesson — what to do
and why, so a reader who stops here still got the point.]

[**[CTA — the first action, e.g., "Open your memory settings now →"]**](url) · *[Micro-copy: time cost, tier, tools needed — e.g., "Twenty minutes. Free tier. No new tools."]*

[Body paragraph(s) setting up the lesson]

**{K}The real shift:** [Callout — the idea behind the tactic. The reframe the
reader should walk away with.]

### [Subhead — a section of the lesson]

[Explanation, every claim cited to a primary source]

### [Subhead — the procedure, e.g., "The twenty-minute move"]

1. [Action]
2. [Action]
3. [Action]

### Bonus: [adjacent tool or platform] (optional)

[A short section applying the same skill somewhere else.]

### [Closing subhead]

[Why this matters now — the news or shift that makes the lesson timely.]
```

## Section guide

- **The hook** — first person, specific, a real problem. Don't open with a
  generic premise. Get the anecdote from the user if you don't have one.
- **The action subhead** — an instruction. It tells the reader what the lesson
  asks of them.
- **The Takeaway** — the whole lesson in one bolded paragraph, placed high. A
  skimmer gets the value from this line alone.
- **CTA + micro-copy** — the first concrete action with the honest cost (time,
  tier, tools). Sets expectations before the reader commits.
- **The real shift** — the conceptual reframe. Every tutorial teaches a tactic
  *and* the idea behind it.
- **The procedure** — numbered and reproducible; each step is an action, not a
  concept. This is the core of the edition. It must work.
- **Bonus** — optional; the same skill in an adjacent tool.
- **The close** — why now. Tie the lesson to a current shift, with a citation.
